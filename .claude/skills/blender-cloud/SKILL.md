# Blender в облачной сессии

Проверено 2026-10-28: Blender 5.2.3 LTS через PyPI-пакет `bpy`. Образец сцены: `blender/test_scene.py`.

## Установка (один раз за сессию, контейнер временный)
```bash
uv venv --python 3.13 <scratchpad>/blenv           # bpy 5.x требует именно Python 3.13
uv pip install --python <scratchpad>/blenv/bin/python bpy numpy   # ~400 МБ, ~40 мин
```
- Скачивание идёт через прокси медленно. ЗАПУСКАТЬ ТОЛЬКО В ФОНЕ: `run_in_background: true`, `timeout: 7200000`. С обычным лимитом 30 мин установка обрывается на полпути.
- `download.blender.org` закрыт, готовый Blender оттуда не скачать. Работает только `bpy` с PyPI.
- Проверка: `blenv/bin/python -c "import bpy; print(bpy.app.version_string)"`.
- Не проверять наличие процесса через `pgrep -f "uv pip install"` в той же команде: он находит сам себя. Использовать `ps -eo pid,etime,args | grep "[u]v pip"`.
- Для режима Eevee нужен `libegl1` и `libgl1-mesa-dri` (`apt-get update && apt-get install -y libegl1 libgl1-mesa-dri`). Но Eevee без видеокарты медленнее Cycles, так что обычно не нужен.

## Запуск без экрана
`<scratchpad>/blenv/bin/python скрипт.py ...`: `import bpy` работает как обычная библиотека. Сцена строится с нуля: `bpy.ops.wm.read_factory_settings(use_empty=True)`.

## Скорость (4 ядра CPU, 16 ГБ ОЗУ, видеокарты нет)
Простая сцена (куб, шар, пол, 2 источника света), 960×540, 32 сэмпла, шумоподавление:
- **Cycles (CPU): 7 с на кадр.** Использовать его.
- Eevee (программный, без GPU): 23–43 с на кадр, хуже.
- Оценка: 24 кадра/с × 30 с = 720 кадров, около 1,5 ч на простую сцену. Лес с персонажем будет заметно медленнее. Перед большим рендером ВСЕГДА замерить 2–3 кадра на реальной сцене и назвать пользователю время.
- Для проб: 640 px и 16 сэмплов. Финал: 1280–1920 px, 64+ сэмплов.
- Длинный рендер запускать в фоне, кадры сохранять в scratchpad, MP4 собирать ffmpeg (`-crf 20`), в репозиторий класть только MP4 и `.blend`.

## Грабли Blender 5
- `Material.use_nodes` и `World.use_nodes` объявлены устаревшими (предупреждение, работает до Blender 6).
- У действия нет `.fcurves`. Линейную интерполяцию задавать ДО вставки ключей: `bpy.context.preferences.edit.keyframe_new_interpolation_type = 'LINEAR'`.
- Камеру наводить через `TRACK_TO` на пустышку (`track_axis='TRACK_NEGATIVE_Z'`, `up_axis='UP_Y'`): ручные углы дают плохой кадр.
- Куб, повёрнутый на 90/180°, выглядит как не повёрнутый: для проверки вращения смотреть промежуточные кадры.

## Честно о качестве
Персонажи собираются кодом из простых форм (шары, капсулы, цилиндры): получатся милые игрушечные герои, а не «как Pixar». Скелет и готовые анимации (Mixamo и т. п.) недоступны без скачивания внешних файлов: проверять доступность прежде, чем обещать.
