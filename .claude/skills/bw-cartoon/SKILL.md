# Чёрно-белый мультфильм кодом

Рабочий образец: `cartoon/test01/` («Пончик и голубь на фонаре», проверен 2026-10-28).
Новый ролик = копия этой папки + новый `scene.js` (таймлайн `T`, персонажи, декорации) + новая партитура в `sound.py`.

## Среда: уже проверено, повторно не диагностировать
Облачная сессия Claude Code (Ubuntu 24.04, 4 CPU, 16 ГБ ОЗУ, без видеокарты, временный контейнер).
- Есть: Node 22 + `require('playwright')` с Chromium (не устанавливать заново!), Python 3 + numpy + Pillow, ffmpeg с libx264/aac, uv.
- Нет: scipy, Blender, ssh-клиента. Исходящий SSH (порт 22) закрыт: к серверу пользователя не подключиться.
- Сеть: PyPI, Google Fonts (`fonts.googleapis.com`, `fonts.gstatic.com`), Ubuntu-репозитории доступны. YouTube и `download.blender.org` закрыты.
- Шрифты с кириллицей уже лежат в `cartoon/test01/fonts/` (Oswald, Caveat, SIL OFL).
- Отправка в GitHub требует установленного Claude GitHub App на `teymuraz009/Haus`. Без него `git push` даёт 403: сразу сказать пользователю и попросить подключить на https://claude.ai/connect-github.

## Конвейер (около 2,5 мин на 13 с видео)
```bash
cp -r cartoon/test01 cartoon/<новый_ролик>   # затем правки scene.js / sound.py
cd cartoon/<новый_ролик>
# 1) пробные кадры раз в секунду; смотреть контактный лист и крупные планы ДО полного рендера
node render.cjs <scratchpad>/stills 0 <последний_кадр> 24
# 2) полная сборка: кадры в scratchpad, MP4 в out/
./build.sh <scratchpad>/frames
```
- `render.cjs` пишет `events.json` (таймлайн + времена шагов + панорама), `sound.py` берёт тайминги оттуда. Звук и картинка всегда синхронны.
- Кадры (PNG) класть только в scratchpad, не в репозиторий.
- Готовое видео отправлять пользователю через SendUserFile (display: render) и коммитить в `out/`.

## Проверенные настройки
- 1920×1080, 24 кадра/с; логические координаты 1280×720, `SC = 1.5`.
- Сжатие: `-crf 27 -tune grain -preset slow`, AAC 160k. Даёт ~7–8 МБ на 13 с. При crf 20 выходит 32 МБ: плёночное зерно раздувает битрейт.
- Громкость микса около −14,5 LUFS, пик −1 dBFS (норма YouTube). Проверка: `ffmpeg -i audio.wav -af ebur128=peak=true -f null -`.
- Темп 90 BPM (`BEAT = 2/3` с), шаги восьмыми (цикл ходьбы = 1 доля), фаза `+0.25`, чтобы касания ног попадали в сетку.

## Стиль (что делает картинку «дорогой»)
- Серые тона на бумаге, контур `#161514`, «дрожание» линий каждые 2 кадра (`BF = floor(i/2)`, функция `jp`).
- Постобработка: сепия (multiply), зерно (overlay из 6 заранее сгенерированных текстур), мерцание, пыль, царапины, виньетка, дрожание кадра.
- Камера с плавным слежением (пружина, просчитана заранее), параллакс: облака 0.15, дальние дома 0.45, улица 1.0, разметка 1.15.
- Приёмы старых мультфильмов: «диафрагма» на открытие и закрытие, титры на карточке, музыка обрывается, когда герой останавливается, «бойнг» на удивление, финальная фраза «shave and a haircut».

## Грабли, на которые уже наступили
- Герой при масштабе 1.0 слишком мелкий в кадре 1280×720: использовать `CS = 1.3` и учитывать `CS` во всех мировых координатах (точка посадки на кепку, взгляд, центр «диафрагмы»).
- При приветствии рука закрывала лицо (похоже на «отдание чести»): угол руки `1.1 ± 0.25` рад, длина 76, ладонь сбоку от лица.
- Голубь в полёте выглядел смазанным: крыло из 5 точек, размах 34.
- `/usr/bin/time` в контейнере нет. Время замерять через `date +%s`.

- Сервер 2 ГБ с проектом «осмотр хирурга» НЕ трогать: для мультфильмов он не используется.
- У пользователя есть GPT для картинок/SVG и Termux + Ubuntu на телефоне (12 ГБ ОЗУ), но текущий рабочий путь — облачная сессия.
