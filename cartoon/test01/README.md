# «Пончик и голубь на фонаре» — тест 01

Чёрно-белый мультфильм в стиле 1930-х, 13,6 с, 1920×1080, 24 кадра/с, стерео.
Всё создано кодом: без готовых моделей, картинок и звуковых библиотек.

**Готовое видео:** [`out/ponchik_test01.mp4`](out/ponchik_test01.mp4)

## Сюжет
1. Титры «ПОНЧИК и голубь на фонаре», открывается «диафрагма».
2. Пончик шагает по улице. Стук шагов совпадает с ритмом музыки.
3. Он останавливается, музыка обрывается. Голубь на фонаре воркует.
4. Пончик поднимает глаза, удивляется, кепка подпрыгивает («бойнг»).
5. Пончик машет и насвистывает, голубь перелетает к нему на кепку.
6. Пончик радостно подпрыгивает. «Диафрагма» закрывается на его лице, финальная мелодия, «КОНЕЦ».

Кот в окне следит глазами за голубем.

## Файлы
| Файл | Что делает |
|---|---|
| `scene.js` | Вся анимация: герой, голубь, город, камера, титры, эффект старой плёнки. Таймлайн в объекте `T` |
| `scene.html` | Страница с холстом; `scene.html?play` открывает анимацию в браузере |
| `render.cjs` | Покадровый рендер в PNG через Chromium (Playwright) |
| `sound.py` | Музыка (пианино, туба, кларнет) и шумы, синтезируются через numpy по таймингам из `events.json` |
| `build.sh` | Полная сборка: кадры → звук → MP4 |
| `fonts/` | Шрифты Oswald и Caveat (лицензия SIL OFL) |

## Сборка
```bash
./build.sh            # около 2,5 минуты, результат в out/ponchik_test01.mp4
```
Нужны: Node.js + Playwright с Chromium, Python 3 + numpy, ffmpeg.
Видеокарта не нужна, достаточно 1–2 ГБ ОЗУ.
