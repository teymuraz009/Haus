# «Винтик и новый друг»: 3D-мультфильм на Three.js + GSAP

35,5 с, 1920×1080, 24 кадра/с, стерео. Всё создано кодом: без готовых моделей, текстур и звуковых библиотек.
**Видео:** [`out/vintik.mp4`](out/vintik.mp4)

## Сюжет
1. Титр «ВИНТИК и новый друг» над утренней улицей.
2. Робот Винтик шагает по тротуару, разглядывает вывески, улыбается в камеру.
3. Замечает цветок в горшке, приседает рассмотреть, и цветок распускается у него на глазах.
4. Из цветка вылетает бабочка, Винтик идёт за ней, она улетает.
5. Шорох в кусте, оттуда выглядывает заяц. Оба пугаются: заяц прячется, Винтик подпрыгивает.
6. Винтик приседает и протягивает руку. Заяц выходит, обнюхивает, радуется. Винтик машет.
7. Уходят по улице вместе. «КОНЕЦ».

## Файлы
| Файл | Что делает |
|---|---|
| `main.ts` | Сцена, персонажи, улица и таймлайн GSAP. Состояние `S` двигает GSAP, позу из него считает `pose()` |
| `render.cjs` | Поднимает Vite (порт 5181), пишет `events.json`, снимает кадры через Chromium |
| `sound.py` | Музыка (укулеле, колокольчики, бас) и шумы (шаги, моторчики, голос робота, заяц, птицы) |
| `build.sh` / `mux.sh` | Полная сборка / склейка готовых кадров и звука в MP4 |

```bash
./build.sh <папка_для_кадров>                       # всё целиком, ~20 мин
node render.cjs <папка> 0 851 36                    # пробные кадры раз в 1,5 с (~40 с)
npx vite --config cartoon/vintik/vite.config.ts     # (из корня) просмотр в браузере: http://localhost:5181
npx tsc -p cartoon/vintik                           # (из корня) проверка типов
```

## Как устроено
- **Персонаж Винтик:** скруглённые детали (`RoundedBoxGeometry`), глянцевый пластик (`MeshPhysicalMaterial` + clearcoat), отражения от `RoomEnvironment`. Шарнирный скелет: таз → корпус → голова, плечо → локоть → кисть, бедро → колено → стопа.
- **Лицо-экран:** canvas-текстура, перерисовывается каждый кадр. Глаза следят за целью, моргают, «^ ^» от радости, «О» от удивления, «?» от любопытства, розовый цвет от восторга.
- **Походка:** фаза шага берётся из пройденного расстояния (`STRIDE`), поэтому ноги не скользят при любом ускорении. Шаги для звука считаются из той же фазы.
- **Взгляд:** голова и глаза поворачиваются к точке интереса, к бабочке или к камере (`look`, `lookBF`, `lookCam`).
- **Камера:** фиксированные планы с наездами и «следящие» планы, привязанные к роботу (`follow`).

## Замеры
Около 1,4 с на кадр в облачной сессии (4 CPU, без видеокарты, WebGL через SwiftShader). Звук собирается за 2 с, громкость −14,6 LUFS.
